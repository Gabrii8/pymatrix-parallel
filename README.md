# Parallel Matrix Multiplication Analysis

_Individual Assignment — Big Data (Task 1, 2025)_

This project implements and benchmarks three different approaches for dense square
matrix multiplication:

- **Sequential:** classic triple–nested-loop algorithm (`O(N^3)`).
- **Parallel:** row-wise decomposition using Python's `multiprocessing` module.
- **Vectorized:** NumPy implementation that leverages highly optimized BLAS/LAPACK
  routines and SIMD instructions.

The goal is to analyse speedup, efficiency, and the impact of vectorization and
parallelism on performance.

---

## Project Structure

- `matrix_ops.py`  
  Core implementations:
  - `multiply_sequential(A, B)`
  - `multiply_parallel(A, B, num_cores)`
  - `multiply_vectorized(A, B)`

- `benchmark.py`
  Runs the benchmarks for different matrix sizes, measures execution times and
  writes a CSV file with:
  - matrix size
  - sequential time
  - parallel time
  - vectorized time
  - speedup
  - efficiency per core
  
  It also calls the plotting script.

- `plot_results.py`  
  Reads the CSV file and generates four plots:
  - `execution_time.png` – execution time vs matrix size (linear scale)
  - `execution_time_log.png` – execution time vs matrix size (log scale)
  - `speedup.png` – speedup of the parallel version vs matrix size
  - `efficiency.png` – efficiency per core vs matrix size

- `results/` *(created at runtime)*  
  - `benchmark_data.csv`
  - the PNG figures generated by `plot_results.py`

 ## How to run 

From the project root (or using the *Run* button / integrated terminal of your editor or IDE, with the project root as the working directory):

### **Runing the complete benchmark**

```bash
python benchmark.py
```
This will:
- Detect the number of available CPU cores.
- Perform the multiplication for different matrix sizes.
- Save the metrics to results/benchmark_data.csv.
- Generate the performance graphs in the results/ folder.

### **Regenerating only the plots (Optional)**
If results/benchmark_data.csv already exists and you only want to recreate the
figures:
```bash
python plot_results.py
```
